# Network Detective 🔍🌐

An enterprise-grade, interactive network infrastructure troubleshooting application powered by fine-tuned prompt paths leveraging the Google Gemini API. Built with React, TailwindCSS, and Node.js/Vercel Serverless Architecture.

## 💡 The Recruiter Insight
I engineered this app to demonstrate how modern AI integrations can accelerate root-cause analysis (MTTR) for Tier 3 network engineering and infrastructure support teams. Instead of passing dummy data strings, this app communicates with a live generative engine under real strict budget optimization limits ($0 cost profile using Gemini free-tier keys).

### Key Architectural Capabilities Showcased:
- **Serverless API Design:** Built-in modular edge architecture using Vercel serverless configurations.
- **Enterprise Prompt Isolation:** Safe backend route segregation ensuring zero client-side exposure of infrastructure API credentials.
- **Production-Ready Theme UI:** Pure terminal shell implementation designed using React Functional Components and custom-configured Tailwind spacing layouts.

## 🛠️ Tech Stack & Architecture
- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js Serverless Functions (`/api/chat`)
- **Core AI Integration:** `@google/genai` (Gemini-2.5-Flash model tier)
